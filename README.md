## 🚀 Featured Projects

### [TruthSplit: Data Reconciliation & Root-Cause Analysis](https://github.com/saxipatel/truthsplit)

Explains why two reports of the same business metric disagree. TruthSplit compares data from CSV, Excel, and PostgreSQL queries, attributes every cent of the gap to proven causes (duplicates, refund policies, reporting cutoffs, definition differences), and reports what it can't explain instead of hiding it.

- Evidence-based discrepancy attribution and what-if simulations
- Investigation history and audit tracking
- **330** backend tests and **20** end-to-end tests, Docker deployment, GitHub Actions CI

**Stack:** Python, FastAPI, PostgreSQL, SQLAlchemy, React, TypeScript, Docker

---

### [DataRescue: Data Reliability & Recovery Platform](https://github.com/saxipatel/datarescue-ai)

A data reliability platform for batch transaction pipelines: detects ingestion failures, validates records against data contracts, quarantines bad data, and supports safe, idempotent recovery.

- Contract validation, duplicate detection, quarantine and dead-letter handling
- Checkpointing, audit logging, and human-approved replay of failed records
- **172** backend tests (**89%** coverage), **23** dbt tests, ~**6,057 records/sec** in benchmarks

**Stack:** Python, PostgreSQL, dbt, FastAPI, Docker, GitHub Actions
